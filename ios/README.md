# RS Receipts — iOS

Not started. This folder is the iOS counterpart to [`android/`](../android), which holds the
whole Gradle project.

The spec both platforms implement is [`README.md`](../README.md) at the repo root; the data
model, export formats and the backup file format described there are meant to be identical on
both, so a backup written on one restores on the other.

Shared, not per-platform:

- [`branding/`](../branding) — icon source and store assets
- [`docs/`](../docs) — setup notes, including the Google Drive registration
